## 과정 개요

본 과정은 NVIDIA Jetson Orin 기반의 온디바이스 환경에서, 딥러닝 기반 컴퓨터 비전과 대규모 언어 모델을 접목하여 Vision–LLM 융합 시각 · 청각 멀티모달 시스템을 직접 구현하는 실습형 Physical AI 개발 과정입니다.

기존 클라우드 기반 AI와 달리 인터넷이나 외부 서버에 의존하지 않고, 모든 실시간 영상 데이터와 대화 과정이 로컬 환경에서 수행되는 Edge AI 구조를 가집니다. 그로 인하여, 카메라로 인식되는 주변 환경과 유저의 음성 입력에 즉각적으로 반응하며 외부 데이터 전송 없이 개인정보 유출 위험이 없는 안전한 AI 시스템을 구현합니다.

<br>

## 학습 목표

• NVIDIA Jetson Orin 기반 Edge 디바이스에서 컴퓨터 비전 및 자연어 처리 기술을 통합하여 실시간 인공지능 시스템을 설계 및 구현  

• 컴퓨터 비전의 기본 개념과 영상 처리 기술을 이해  

• 딥러닝의 기본 구조를 학습  

• GPU 기반 딥러닝 추론 구조와 CUDA 가속 컴퓨팅의 원리를 이해  

• 객체 검출 및 이미지 분류 모델을 활용하여 실시간 비전 시스템을 구현  

• Gemma 기반 경량 대형 언어 모델을 활용하여 자연어 처리 및 생성 기능을 구현  

• 비전 모델과 언어 모델을 통합한 멀티모달 인공지능 시스템을 설계  

• Jetson 기반 엣지 환경에서 AI 모델의 경량화 및 최적화를 수행

## 평가 기준

본 과정은 출석, 수업 태도(실습), 지필고사, 프로젝트 및 과제의 총 4개 항목을 기준으로 평가합니다. 각 항목의 세부 평가 기준은 다음과 같습니다.

| 항목 | 비율 |
|---|---:|
| 출석 | 10% |
| 태도 | 10% |
| 지필고사 | 30% |
| 프로젝트 및 과제 | 50% |
| **Total** | **100%** |

### 출석
매 수업마다 출석 확인을 위한 서명을 진행합니다. 출석 서명은 반드시 본인이 직접 작성해야 하며, 타인의 출석을 대신 확인하거나 타인에게 대리 서명을 요청하는 행위가 적발될 경우 대리 서명자와 이를 요청한 학생 모두에게 불이익이 적용됩니다. 지각하더라도 출석 확인이 가능하므로 늦더라도 수업에 참여하시기 바랍니다.

### 태도
본 과정은 실습 중심으로 운영되므로, 수업 태도의 객관적인 평가를 위해 당일 수업에서 작성한 실습 결과물을 기준으로 평가합니다. 실습 결과물의 완성도에 따라 회당 0점, 0.5점, 1점을 부여합니다. 당일 실습 결과물은 해당 수업일 오후 6시까지 제출해야 하며, 제출 기한을 반드시 준수하시기 바랍니다.

### 지필고사
지필고사는 과정 마지막 주에 실시하며, 실습 수행 능력과는 별개로 그동안 수업에서 다룬 이론에 대한 이해도를 평가합니다. 시험은 총 10문항의 서술형으로 구성되며, 각 문항은 답변의 정확성, 핵심 개념에 대한 이해도 및 내용의 완성도를 기준으로 0점부터 3점까지 1점 단위로 부여합니다.

### 프로젝트 및 과제
매 수업마다 해당 수업의 학습 내용을 바탕으로 한 과제가 부여되며, 다음 수업 시작 전 오후 1시까지 제출해야 합니다. 프로젝트는 총 3회 진행합니다. 이 중 2개는 수업에서 학습한 개별 주제와 기술을 적용하는 단기 프로젝트이며, 나머지 1개는 수업에서 학습한 내용을 종합하여 최종 결과물을 제작하는 프로젝트입니다. 제출 마감 날짜 및 시간은 각 프로젝트마다 별도로 안내할 예정입니다.

모든 과제와 프로젝트는 개별 수행을 원칙으로 합니다. 평가는 제출물뿐만 아니라 제출 이후 진행되는 발표를 통해 학습 내용에 대한 이해도, 결과물의 완성도 및 수행 과정에 대한 설명 능력을 종합적으로 반영합니다.

## 제출 방식

과제 제출 시에는 각 과제가 부여된 날짜를 이름으로 한 별도의 폴더를 생성하고, 해당 폴더 안에 수업 시간에 작성한 실습 파일과 구분되는 독립된 과제 파일을 제출해야 합니다. 또한, 제출한 파일의 실행 방법, 필요한 의존성 및 기타 참고 사항을 명시한 `README.md` 파일을 함께 작성하여 해당 폴더에 포함해야 합니다.

프로젝트 제출 시에는 `Project01`과 같은 형식으로 프로젝트별 폴더를 생성하고, 해당 폴더 안에 독립적으로 실행 가능한 파일과 필요한 부가 파일을 포함하여 제출해야 합니다. 또한, 과제 제출 기준과 동일한 `README.md` 파일을 작성하여 함께 제출해야 합니다. 최종 프로젝트의 경우, 추가로 발표 자료를 `.pdf` 형식으로 함께 제출합니다.

모든 과제, 프로젝트 및 실습 파일은 본인 계정의 GitHub Repository에 제출해야 합니다. 제출 시각은 해당 파일이 포함된 commit의 기록 시각을 기준으로 합니다. Commit 메시지에는 변경 사항과 작업 내용을 명확하게 설명하는 적절한 내용을 작성해야 합니다. "update", "fix", "test" 등 작업 내용을 구체적으로 파악하기 어려운 모호하거나 무의미한 메시지를 작성할 경우 감점될 수 있습니다.

## 채점 기준

과제 및 프로젝트는 아래에 명시된 평가 항목별로 0-10점의 개별 점수를 부여하고, 각 항목의 점수에 해당 항목의 반영 비율을 적용하여 합산하여 평가합니다. 항목별 점수 합산 후에는 종합 가중치를 적용하여 최종 점수를 산출합니다. 종합 가중치는 $0.0 < w < 1.0$ 범위의 값으로, 본인이 작성한 코드와 구현 과정에 대한 이해도를 기준으로 산정됩니다. 즉, 결과물의 완성도가 높더라도 본인의 코드에 대한 이해도가 부족한 경우, 해당 이해도에 비례하여 최종 점수가 조정됩니다.<br>

$$
\text{\textit{최종 점수}} \hspace{4pt} = \hspace{4pt} w \sum_i \text{\textit{배점}}_i \hspace{2pt} \cdot \hspace{2pt} \text{\textit{점수}}_i
$$

과제와 프로젝트 배점 비율은 다음과 같습니다.<br><br>

## 제출 기한 규정

실습, 과제 및 프로젝트는 앞서 명시된 각 항목의 제출 기한을 준수해야 합니다. 정당한 사유로 기한 내 제출이 어려운 경우에는 반드시 사전에 이메일로 해당 사유를 통보해야 합니다. 다만, 사전 통보가 어려운 긴급한 상황이 발생한 경우에는 상황이 해소된 후 관련 증빙 서류를 제출하여 사유를 소명할 수 있습니다.

제출 시각은 GitHub Repository에 기록된 해당 commit의 시각을 기준으로 판단합니다. 제출 기한을 초과한 경우 1회에 한하여 제출을 인정하며, 제출 기한을 2회 이상 초과한 경우에는 전체 성적에서 반영 비율이 더 높은 항목의 평가 결과를 우선적으로 인정합니다. 그 외 기한 초과 제출물들은 성적에 반영되지 않습니다.

## 생성형 AI 사용에 대한 규정

본 과정에서는 생성형 AI의 사용을 허용합니다. 다만, 생성형 AI에 대한 과도한 의존은 엄격하게 평가하며, 본인의 이해와 기술적 숙고 없이 AI가 생성한 결과물에 의존하는 경우 평가 점수에 불이익이 적용됩니다.

실습, 과제 및 프로젝트는 수업에서 제공되는 자료와 학습 내용을 바탕으로 충분히 수행할 수 있도록 구성되어 있습니다. 학습 과정에서 어려움이 발생할 경우, AI에 의존하기보다는 수업 중 혹은 수업 외 시간에 문의하여 문제를 해결하는 것을 권장합니다.

과제 및 프로젝트 평가 과정에서는 제출물과 관련된 세부 질문을 통해 본인의 구현 내용과 기술적 원리에 대한 이해도를 확인합니다. 이러한 질의응답 결과는 평가 점수에 반영되며, 제출물의 완성도가 높더라도 본인이 작성한 코드와 구현 과정을 충분히 이해하지 못하거나 명확하게 설명하지 못하는 경우, 단순 감점이 아닌 최종 점수에 배율로 반영됩니다. 따라서 생성형 AI를 활용하더라도 작업 전반을 AI에 의존하여 맡기기보다는, 본인의 지식과 역량을 바탕으로 시스템을 직접 설계하고 세부적인 작업의 보조 수단으로 AI를 활용하는 방향을 지향합니다. 이를 통해 독립적인 설계 및 구현 역량을 기르는 동시에 생성형 AI를 효과적으로 활용하는 방법을 익히도록 합니다.
